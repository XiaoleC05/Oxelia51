# Oxelia51 前端汉化术语表

**版本**：v1.2 | **日期**：2026-08-21
**用途**：本仓 web/（原 langfuse-token fork，已并入）中文文案统一口径，后续新增/修改 UI 文案必须遵循本表。
**说明**：i18n 路由已于 2026-08-05 移除（不再有 /en 语言路由与浏览器语言重定向），本表从「翻译规范」转为「中文文案标准」——全站统一用中文，术语按本表落地。
**去 AI 化原则**：面向用户的文案避免 LLM/AI 直译，统一用「模型」（如 LLM Connections → 模型连接、AI 工具 → 模型工具）。

> 注：langfuse 原生功能（追踪/提示词/评估/演练场/标注/计费/仪表盘组件等）已从 web 删除，
> 对应术语条目已移除；历史版本中的原生术语仅作归档参考，不再作为文案口径。
