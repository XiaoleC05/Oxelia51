# 需求规格说明

**项目**：oxelia51.com | **版本**：3.0.0 | **日期**：2026-07-27

---

## 1. 用户系统

采用 Langfuse 自带的用户系统（注册、登录、邮箱验证、API Key 管理）。现有 Oxelia51 用户表不再使用。

## 2. 代理网关

### 2.1 支持的 LLM 供应商

- Anthropic (Claude)
- OpenAI
- DeepSeek
- Google Gemini
- Moonshot
- 智谱 (GLM)

### 2.2 管理界面

提供简单的状态页（运行状态、QPS、延迟），可点击进入完整的配置管理页面（限流规则、路由策略）。

### 2.3 数据采集方式

采用 API 代理模式：用户修改环境变量指向代理地址，代理转发请求并记录 Token。

API Key 不存储，仅转发。提供 oxelia51.com 在线使用和自部署两种形态。

## 3. Token 统计与展示

### 3.1 统计维度

按时间（日/周/月）、模型、项目、会话四个维度统计。

### 3.2 会话定义

客户端驱动。AI 工具通过 `X-Session-ID` 请求头传递会话标识，一次对话存储空间 = 一个会话。代理不按时间间隔硬切。

### 3.3 成本显示

内置各模型定价表。默认显示人民币（CNY），可点击按钮切换为美元（USD）。汇率取当日中国银行中间价，通过定时任务每日更新。

### 3.4 图表库

ECharts。

## 4. 项目管理

用户可自定义分组规则（按模型、按时间、按标签）。

## 5. 告警

### 5.1 告警类型

- 预算告警：当月消费达到预设阈值时通知
- 异常检测：单日 Token 用量同比飙升 3 倍时通知

### 5.2 通知通道

- 站内通知
- 邮件
- Webhook（可接钉钉、微信、飞书）

## 6. 管理后台

### 6.1 保留

DormGuard 电费查询、SecretStore 凭证管理、服务器监控、IP 白名单。

### 6.2 新增

Token 平台的用户管理和系统配置功能。

## 7. 部署形态

### 7.1 交付方式

oxelia51.com 在线服务和 GitHub 自部署包共享同一代码库。

### 7.2 自部署形态

两种都提供：
- Docker Compose 一键部署（Langfuse 全家桶，组件多）
- 单二进制文件 + systemd（Go 代理网关，轻量单体）

## 8. 前端

### 8.1 策略

混合模式：核心仪表盘用 Langfuse 的，自定义面板（Token 统计、成本分析）全新写。

### 8.2 设计系统

保留双主题（Cozy/Cosmos）的 CSS 变量体系，主题色需重新定义以匹配 Langfuse UI。

## 9. 范围

基于 Langfuse + Helicone 融合，开发完整功能。实现细节见 `4-detailed-design.md`。
