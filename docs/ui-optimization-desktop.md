## 一、主界面视觉升级

### 1.1 品牌区（顶栏左侧）

- 把 CSS 色块换成**品牌伴星 glyph**（打包进 ui 资产的 PNG/SVG，深主题用白环版、浅主题用黑环版）+ 字标「Oxelia51」（Manrope 300 转曲 SVG 或文字）+ 副标「本地账本」（muted，12px）。
- 顶栏高度 52px → **56px**，品牌区与导航间距 24px，右区（代理状态 + 主题切换）保持。

### 1.2 导航

- 维持顶部标签式（5 个 Tab 数量少，无需侧栏），但升级样式：激活态 = accent 文字 + 底部 2px accent 指示条（替代现在的浅色药丸底），hover 过渡 150ms。
- Tab 顺序保持：总览 / 项目 / 会话 / 告警 / 设置。

### 1.3 内容区层次

- 统一卡片语言：圆角 12px、1px `--ox-border` 描边、cosmos 下卡片比底色亮一档（`--ox-bg-alt`）；阴影最多两档（卡片无阴影，浮层一档）。
- 栅格：总览页指标卡 4 列（1280px+）/ 2 列（窄），间距 16px；数字一律 `tabular-nums`。
- 状态表达统一：「代理在线 · :17800」用绿色圆点 + 文字（现状保留），离线改红色圆点 + 「代理离线 · 点击排查」可点击跳转设置页代理小节。
- 空态规范（全局）：图标（伴星 glyph 弱化版 48px，12% 透明度）+ 一句话说明 + 一个主按钮。禁止裸文字「暂无数据」。

### 1.4 字号/字重阶梯（全端统一）

```
页面标题 20px/600 · 卡片标题 14px/600 · 正文 13.5–14px/400
辅助说明 12–12.5px/400 · 大数值 24–28px/600（tabular-nums）
```

## 二、模型空态（幽灵数据清除）

**原则：任何下拉/列表/图表的数据只来自真实记录，界面不允许出现占位数据。**

1. `AlertsTab` 模型下拉改造：
   - 选项 = `全局（所有模型）` + **sidecar 模型统计接口返回的真实模型列表** + `其他（手填）`；删除三个硬编码模型。
   - 接口无数据时：下拉只保留「全局」+「其他（手填）」。
2. 全端空态检查点（逐屏过一遍）：总览图表、项目列表、会话列表、告警历史——无数据时统一显示 §1.3 的空态组件，文案示例：
   - 总览：「还没有 Token 记录——把模型工具的 BASE_URL 指向本地代理即可开始记账」+「复制命令」按钮
   - 项目/会话：「暂无记录」+ 指向快速开始的链接
3. 验收：全新安装、零数据启动，任何界面不出现 claude/gpt/deepseek 等占位字样。

## 三、字体辨识度

1. **中文字体栈显式化**（web 与桌面端同步）：
   ```css
   font-family: "Manrope", "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", system-ui, sans-serif;
   ```
   （现状 Manrope 后直接接系统回退，Windows 中文渲染偏细。）
2. **可选升级（推荐）**：引入 **MiSans**（或 HarmonyOS Sans SC）自托管 woff2 作为中文主字体——屏幕显示优化、字重齐全，品牌感立刻统一。注意许可（MiSans 免费可商用）与包体积（子集化后 < 1MB）。桌面端打包进 ui 资产，web 端放 `web/public/fonts/`。
3. **对比度达标（WCAG AA 4.5:1）**：
   - cosmos：`--ox-text-muted` `#737373` → 建议 `#8f8f8f` 起
   - cozy：`--ox-text-muted` `#857a6e` → 建议 `#6f6459` 方向（实测对比度后定稿）
   - 辅助文字最小 12px，低于 12px 的统计标签（现在 mock 里有 10px）全部提到 12px。
4. **字重纪律**：正文 400、强调 500/600；除字标外不使用 300。

## 四、应用图标（黑底红点 → 品牌伴星）

### 4.1 图标设计适配

以品牌规范几何（月环 + 右下 45° 星点，见 brand-spec.md）为基础做**图标级适配**，不是直接缩放：

- **画布**：内容区占画布 80%（操作系统会再裁圆角/蒙版，四周留安全边距）。
- **底**：深色圆角方块 `#0A0A0A`（圆角按平台：macOS 交给系统蒙版用方形源图；Windows 方形/圆角均可）。
- **形**：白环 `#FAFAFA` + 星点 `#E5484D`。
- **小尺寸语义版（16/24/32px 专用）**：线宽加粗 ~35%、星点放大 ~40% 并更贴近月环——保证 32px 下仍能读出「环 + 点」而不是一个模糊红球（现状 32x32.png 就是纯红球，必须替换）。

### 4.2 交付物（一次生成全套）

| 文件 | 说明 |
|---|---|
| `icon.ico` | **多层** 16/24/32/48/64/128/256 —— 文件管理器/任务栏/Alt+Tab 各取所需（现状层数不足是"陈旧感"主因） |
| `icon.icns` | macOS 全套尺寸 |
| `Square*.png` / `StoreLogo.png` | Windows 所需各尺寸，全部用新图标重出 |
| `app-icon.png` | 1024 主图更新 |

生成后走 `tauri icon` 标准流程或直接替换 `src-tauri/icons/` 全套，重新打包验证：桌面快捷方式、任务栏、Alt+Tab、文件管理器 exe 缩略图、安装器界面五处。

## 五、标题栏现代化

两个方案，**推荐 B**：

**方案 A（最小改动）**：保留系统标题栏，把窗口标题从「Oxelia51 · 本地账本」简化为「Oxelia51」，确认任务栏/标题栏使用新图标。成本低，但视觉仍是系统默认。

**方案 B（推荐，现代感）**：`tauri.conf.json` 设 `decorations: false` 自定义无边框窗口 + 自绘标题栏：
- 左侧：伴星 glyph 16px + 「Oxelia51」（13px/500）——与应用内顶栏合并为一行，节省 30px 纵向空间；
- 右侧：最小化 / 最大化 / 关闭三键（hover 分别灰/灰/红 #E81123 遵循 Windows 习惯），用 Tauri 内置 `window.startDragging()` 拖曳区（标题栏空白处 `data-tauri-drag-region`），双击切换最大化；
- 保留系统窗口特性：Aero Snap、圆角（Windows 11 自动）、阴影；
- macOS 下用 `hiddenTitle: true` + `titleBarStyle: "Overlay"`，红黄绿交通灯保留。
