## Oxelia51 是什么

Oxelia51 是一个**本地优先的个人 Token 记账本**：只需要改一行环境变量，让模型工具（Claude Code、Cursor、ChatGPT 等）的 API 请求经过一个代理，自动记录每一次调用的 Token、成本与异常，然后在仪表盘上多维度查看。

- **零侵入**：不装 SDK、不改代码，只改环境变量
- **多维统计**：按时间、供应商、Agent 拆解用量与成本
- **本地优先**：桌面应用数据全部保存在本地，账户用于跨设备同步与云端查看
- **开源**：MIT 许可证，代码全开源

> 安装时遇到系统提示的解决办法见[桌面应用 → 安装时遇到系统提示怎么办](/docs/desktop)。

## 云平台 5 分钟上手

云平台主要提供已同步数据的查看与跨设备恢复：

1. **注册并登录** → [注册](/auth/sign-up)，登录仅在使用云平台时必需
2. **桌面端接入代理**，把模型工具指向本地代理（见下）
3. **登录同步**：桌面端登录账户后可把本地账本同步到云端
4. **打开云平台仪表盘**，按供应商 / Agent 查看 Token 与成本统计

## 桌面应用（已发布 v0.1.x）

桌面应用已发布，支持 Windows / macOS / Linux，全功能本地使用、无需登录。详见[桌面应用](/docs/desktop)。

## 核心概念

- **供应商**：提供大模型的平台（Claude / DeepSeek / OpenAI / 智谱 …），代理路径里的 slug 决定请求转发给谁
- **Agent**：你使用的客户端软件（Claude Code / Cursor / CC Switch / Trae …），记录会自动按工具识别
- **代理**：介于模型工具与真实 API 之间的转发层，负责自动落账；密钥只转发、不落库
