## 为什么需要账户

使用 Oxelia51 **不强制注册**：桌面应用全功能本地使用，文档、下载、社区全部匿名开放。

账户仅在以下场景需要：

- **跨设备使用 / 同步**：桌面端登录账户后，多台设备之间同步账本（按事件去重合并）
- **云平台**：数据落云端时，账户用于识别数据归属

## 注册

在[注册页](/auth/sign-up)填邮箱和密码即可完成注册。注册后系统会发一封验证邮件到你的邮箱，建议尽快点击链接完成验证。

## 忘记密码

在[登录页](/auth/sign-in)点击「忘记密码」，输入注册邮箱后会收到一封重置密码邮件：

1. 点击邮件里的链接进入重置页面
2. 设置新密码
3. 用新密码重新登录

重置链接具有时效性，过期需要重新发起一次。

## 修改密码

已登录状态下，在云平台的账户设置里输入旧密码并设置新密码即可，不需要走邮箱验证。

## 账户与设备的关系

一个账户可以在**多台设备**上登录桌面端。每台设备都有独立的本地账本，登录同一账户后：

- **上传**：把本机的账本事件同步到云端
- **下载**：把云端已有的事件（含其他设备上传的）合并进本机

账本事件用唯一 ID 去重，多台设备之间不会重复计数，也不会互相覆盖。详见[云平台使用](/docs/cloud)。
