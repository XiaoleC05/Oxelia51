云平台是 Oxelia51 的在线版本：主要提供**已同步数据的查看与跨设备恢复**。桌面端负责日常本地记账与代理接入；登录云平台后可查看云端备份的 Token 统计，并在更换设备时恢复历史账本。

## 注册与登录

- **使用云平台需要注册登录**（数据要落云端）；但浏览文档、下载、社区不需要登录
- 注册与登录入口在[登录页](/auth/sign-in)与[注册页](/auth/sign-up)；登录成功后默认进入 /app 个人工作台
- 账户同样用于跨设备同步
- 忘记密码、账户与设备的关系等细节见[账户与登录](/docs/account)

## 数据怎么同步到云端

桌面端「设置 → 多设备同步」登录账户后，可把本地账本上传 / 下载到云端。同步只搬运**统计数据**（模型名、Token 数、成本、时间戳等），**不含 API Key、不含请求/响应内容**。

同步的去重规则：

- 每条账本记录有唯一 **event_id**，上传和下载都按这个 ID 去重，同一条事件不会在云端或本地重复计数
- 上传游标和下载游标分别独立维护，互不影响——上传中断后重试，不会重复上传已成功的部分
- 正常情况下"冲突数"应该恒为 0（冲突指同一 event_id 内容不一致，理论上不该发生，只是一层防御性检测）；如果你看到非 0 的冲突数，属于异常情况，欢迎反馈

多台设备登录同一账户后：**新设备下载 = 合并进本机账本**，不会覆盖已有数据；本机新产生的事件下次同步时上传到云端。

已同步的账本可在云平台「/app 设置 → 同步账本」查看设备列表与近 30 日汇总，并管理同步密钥（可断开某台设备的同步）。

## 按供应商与 Agent 查看

云平台个人工作台与桌面端口径一致：

- **供应商消耗**：按提供大模型的平台（Claude / DeepSeek / OpenAI / 智谱 …）聚合
- **Agent 消耗**：按你使用的客户端软件（Claude Code / Cursor / CC Switch / Trae …）聚合

## 支持的模型与供应商

跟桌面端代理是同一套路由表，完整列表（79 条内置路由 + 分类）见[桌面应用 → 配置本地代理](/docs/desktop)，这里不重复维护第二份列表以免过时。

成本按已配置的模型定价自动换算；未配置定价的模型成本按 0 计，供应商 / Agent 页的成本列会显示「未配置定价」，不虚构。

## 云端告警

云平台的预算超限、异常用量提醒走的是独立的后台批处理管道，跟桌面端本地告警不是同一套机制、触发延迟也不同，详见[设置预算告警](/docs/alerts)。
