本文是从下载到精通的完整使用手册：下载安装、逐页界面介绍、核心功能、计费逻辑与常见教学场景。

## 一、下载与安装

到[下载页](/download)下载对应平台的应用并安装。启动后应用会**内置一个本地代理**（默认 `127.0.0.1:17800`），顶栏会显示「代理在线」。

**安装时遇到系统提示**（SmartScreen「Windows 已保护你的电脑」、macOS「无法验证开发者」等）的解决办法，见[桌面应用 → 安装时遇到系统提示怎么办](/docs/desktop)。

## 二、三步上手

1. **指向本地代理**：在「接入」页选择供应商，复制代理地址，配置到你的模型工具（详见下文）。
2. **自动落账**：之后的每一次模型调用，Token 与成本自动记录，无需任何操作。
3. **打开仪表盘**：在「总览」页按供应商 / Agent / 模型查看用量与成本。

## 三、界面总览（逐页介绍）

### 顶栏

- **标签导航**：总览 / 接入 / 供应商 / Agent / 告警 / 设置
- **代理状态**：左侧显示「代理在线 · :17800」；代理未运行时会显示「代理离线」，点击可直接跳转设置排查
- **悬浮统计按钮**（四宫格图标）：打开/隐藏悬浮卡片
- **主题切换**：深色（Cosmos）/ 浅色（Cozy）一键切换
- 右上角为窗口控制（最小化 / 最大化 / 关闭）

### 总览页

打开应用后默认进入总览，是「Token 花在哪」的全局视图：

- **页头**：标题 + 日期范围（全部 / 近7日 / 近30日 / 近90日），切换后下方统计联动
- **统计卡**：今日 / 近7日 / 近30日 / 累计 的 Token、请求数、成本
- **近 14 天用量趋势**：每日 Token 柱状图，定位异常时段
- **排行**：按供应商 / 按 Agent / 按模型三个排行，**前三名红色渐变**（由深到浅）一眼看清主要消耗
- **空态**：全新安装无数据时显示首次接入引导（选择供应商 + 复制地址/命令），不会展示空卡片

### 接入页

把模型工具接上代理的地方：

- **搜索**：按名称/简称搜索供应商（如 deepseek、kimi、zai）
- **三分类**：国外主流 / 国内主流 / 第三方平台，共 **80+ 个预设接入项**（内置 **79 条路由**，其余待接入）
- **自定义供应商**：预设之外的平台可在设置/接入页自填 API 地址与协议（openai / anthropic），地址只需填域名/路径部分、自动补全 `https://`，本地存储、即加即用；字段规则与常见报错见[自定义供应商接入](/docs/custom-provider)
- **每张卡片**：
  - **「复制地址」**（红色主按钮）：复制该供应商的本地代理地址
  - **「官网」**：跳转该供应商官网，核对最新价格与文档

### 供应商页

按 **LLM 平台**（Claude / DeepSeek / OpenAI / 智谱 …）聚合用量与成本。每一行显示：Token、请求数、成本、涉及模型数、最近使用时间。**点击某供应商**可下钻：该供应商被哪些 Agent 使用、各模型明细。

### Agent 页

按**你使用的软件**（Claude Code / Cursor / CC Switch / Trae …）聚合用量与成本。记录会自动按工具识别。**点击某 Agent** 可下钻：该 Agent 用了哪些供应商 × 模型。

> **供应商 = 提供大模型的平台；Agent = 你使用的客户端软件。** 这是 Oxelia51 统计的两个核心维度。

### 告警页

设置预算阈值，防止费用失控：

- **预算列表**：每条独立，显示每日预算、今日已用、使用比例与触发状态
- **添加预算**：维度可选 **全局 / 单个供应商 / 单个 Agent / 单个模型**，各自独立
- 超限时触发**系统通知**

### 设置页

- **本地代理**：监听地址说明（`127.0.0.1:17800` 固定，本地优先）
- **外观主题**：深色 Cosmos / 浅色 Cozy
- **悬浮卡片显示内容**：勾选卡片显示哪些数据（今日 Token / 今日成本 / 请求数 / 模型 Top5）；「重置位置」可恢复悬浮卡片的默认位置
- **模型定价**：成本核算用的单价表（USD / 1M tokens），可增删改、一键填入参考价、保存
- **模型价格参考**：**77 个模型**的参考价表（详见下节）
- **多设备同步**：登录云平台账户后上传 / 下载本地账本，多设备按事件去重合并
- **关于**：版本、官网、下载、反馈、GitHub、MIT 许可证

### 悬浮统计卡片

顶栏「悬浮统计」打开的桌面悬浮小窗：

- **始终置顶**、无边框、不进任务栏，可拖到屏幕任意角落，位置自动记忆（设置页「重置位置」可恢复默认位置）
- **实时刷新**：每 2.5 秒更新一次
- 显示今日 Token、今日成本、请求数、今日模型 Top5 排名（前三名红色渐变）；可在设置页勾选要显示哪些
- 点右上角 ✕ 隐藏，再点顶栏按钮重新呼出

## 四、核心功能详解

### 日期范围

总览、供应商、Agent 页顶部都可切换时间范围（全部 / 近7日 / 近30日 / 近90日），统计与排行随之联动。排行只统计所选范围内的数据。

### 排行红色高亮

所有排行的前三名用品牌红渐变标注（第1名最深 → 第3名最浅），第 4 名起恢复主题色。

### 模型价格参考与币种切换

设置页的「模型价格参考」是一张**选型参考表**：

- **77 个模型**，覆盖 Anthropic / OpenAI / DeepSeek / Kimi / 智谱 / 通义 / 豆包 / Gemini / xAI / Mistral / MiniMax / 阶跃 / 百川 / Meta 等
- 按 **输入价** 或 **综合成本**（= 输出×0.6 + 输入×0.4）排序，可升序/降序
- 可按供应商筛选
- **美元 / 人民币一键切换**：人民币按每日更新的汇率换算（来源：欧央行基准；离线回退上次成功值 / 内置参考值），汇率来源与日期标注在表下方
- 价格为**参考价**，以各厂商官网为准

### 模型定价与成本核算（计费逻辑）

**不同模型单价不同，按模型精确计费。** 具体逻辑：

```text
成本 = Σ( 该模型的 prompt_tokens ÷ 1M × 它的输入单价
          + 该模型的 completion_tokens ÷ 1M × 它的输出单价 )
```

- 每次请求记录 `model`（请求里的模型名）+ `prompt_tokens` + `completion_tokens`
- **按模型名精确匹配**「设置 → 模型定价」里的单价；供应商 slug 只决定转发给谁，计费与供应商无关
- **没配置定价的模型：成本按 0 计，界面显示「未配置定价」**，不虚构
- 「模型价格参考」表只是选型参考，**不会自动套到成本**；要算成本，需在「模型定价」里保存（可点「填入常见模型参考价」再改）

### 四维告警

预算可按 **全局 / 供应商 / Agent / 模型** 四个维度分别设置，每条独立生效。超限时触发系统通知（桌面本地，不依赖云端）。

### 悬浮卡片字段配置

设置页「悬浮卡片显示内容」可勾选卡片显示：今日 Token、今日成本、请求数、今日模型 Top5。勾选即时生效并保存。

### 多设备同步

在设置页「多设备同步」用云平台注册邮箱+密码登录，即可把本地账本上传到云端或从云端下载；换新设备时登录同一账户、从云下载即可恢复账本。多设备数据按事件去重合并；仅在你主动点同步时数据上行，本地优先、云端是副本。已同步的账本可在云平台「/app 设置 → 同步账本」查看设备列表与近 30 日汇总，并管理同步密钥（可断开）。

## 五、使用教学

### 首次接入（3 分钟）

1. 打开「接入」页，搜索你使用的供应商（如 deepseek）
2. 点**「复制地址」**，得到 `http://127.0.0.1:17800/api/proxy/deepseek`
3. 把地址配置到你的模型工具：
   - 支持环境变量的工具（Claude Code 等）：`export OPENAI_BASE_URL="http://127.0.0.1:17800/api/proxy/deepseek"`
   - 支持自定义 Base URL 的工具（CC Switch 等）：把地址粘进输入框
   > 地址**必须含 `/api/proxy/<供应商slug>` 前缀**，否则请求 404、不落账。
4. 发一条真实请求，回「总览」看是否落账

### 日常查看

- 总览页看今日/累计消耗与趋势，切换日期范围定位异常时段
- 想知道哪个平台最烧钱 → 供应商页；哪个工具最烧钱 → Agent 页
- 点某供应商/Agent 下钻看具体模型明细

### 成本核算

1. 设置页「模型定价」→「填入常见模型参考价」→ 按需修改 →「保存定价」
2. 之后总览、供应商、Agent 各处的成本都按这些单价实时换算
3. 想看美元还是人民币 → 在「模型价格参考」或总览成本处切换币种

### 设置告警

1. 告警页 → 添加预算
2. 选维度（如「模型」= deepseek-chat），填每日 Token 上限
3. 保存后，今日用量达到上限会弹系统通知

## 六、常见问题

- **没有数据**：确认请求真的走了代理（`BASE_URL` 是否含 `/api/proxy`），先用一条真实请求验证
- **成本显示「未配置定价」**：该模型还没在「模型定价」里填单价，填好并保存即可
- **供应商没有**：预设目录覆盖 80+ 接入项（内置 79 条路由）；遗漏的可提需求，或在设置/接入页添加自定义供应商（自填 API 地址与协议）
- **安装被系统拦截**：见[桌面应用 → 安装时遇到系统提示怎么办](/docs/desktop)
- 更多问题见[FAQ](/docs/faq)，报错信息对照见[常见错误排查](/docs/troubleshooting)
